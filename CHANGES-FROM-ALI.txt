How to push it to your repo (school-bus-ahmedservice)
Do NOT delete your folder first: it has your .env and other local files that git ignores.
1. In your local clone: git pull
2. Copy everything from this folder into your repo folder, and choose "Replace" for every file.
3. Delete the 6 files listed under "Deleted" above, if they are still there.
4. npm ci
5. npm test   (expect 80 passed, 13 skipped)
6. git add -A
7. git status   (check: only the files listed above, no .env, no node_modules)
8. git commit -m "Add login rate limit, CloudWatch alarms, security docs; remove alerts and holidays"
9. git push
